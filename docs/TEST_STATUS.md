## 主要な問題と対応状況

### 1. GUI関連テストのエラー (59エラーの主要因)
**問題**: `tests/unit/gui/test_main_frame.py`でwxPythonのGUI初期化エラー
**原因**: テスト環境でのwxAppインスタンス不在
**対応**: wxPythonのモック化またはヘッドレステスト環境の構築が必要

### 2. 統合テストの失敗 (28失敗)
**問題**: 認証フロー、投稿フロー、設定フローの統合テスト失敗
**原因**: 
- モックとスタブの不整合
- 非同期処理のタイミング問題
- シングルトンパターンのテスト間干渉

**対応**: 各統合テストのfixture改善とテスト分離の強化が必要

### 3. E2Eテストの課題
**問題**: 実際のBluesky APIとの連携テストが未実装
**対応**: テスト用アカウントまたはAPIモックサーバーの準備が必要

## テスト実行コマンド

```bash
# 基本実行
pytest

# カバレッジ付き
pytest --cov --cov-report=html

# 失敗テストのみ再実行
pytest --lf

# 並列実行（高速）
pytest -n auto

# 特定マーカーのみ
pytest -m unit          # 単体テストのみ
pytest -m integration   # 統合テストのみ
pytest -m "not slow"    # slowマーカー以外

# 詳細出力
pytest -v
```

## メンテナンス指針

1. **新機能追加時**: 必ず対応するテストを同時に作成
2. **バグ修正時**: まず失敗するテストを書いてから修正
3. **リファクタリング時**: テストを先に更新してから実装変更
4. **コードレビュー**: テストカバレッジの確認を必須とする
